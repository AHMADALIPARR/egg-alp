MATHEMATICAL DEFINITIONS AND ALGORITHMS

Let X[i,t] be an optional integer count for device i at UTC second t. Valid count: 0 ≤ X[i,t] ≤ 200. Missing is an explicit option/nullable value, never zero-imputed.

A. Binomial reference: X ~ Binomial(200, 1/2); E[X]=100; Var[X]=50; SD=sqrt(50). Exact probability mass: P(X=k)=choose(200,k)2^-200.
B. Standardization: z[i,t]=(X[i,t]-100)/sqrt(50) for observed cells.
C. Network score under independent-device null: Z[t]=sum_{i in V_t} z[i,t]/sqrt(|V_t|), for nonempty V_t. Explicitly test independence; if covariance is nonzero, calibrate using empirical covariance and appropriate temporal nulls. Never divide by zero.
D. Device-count Pearson goodness-of-fit / likelihood-based comparison to the binomial reference with careful expected-bin treatment; compare empirical moments, tails, and quantiles. Predeclare tests.
E. Shannon entropy H(X)=-sum_k p(k) log2 p(k); entropy bound 0≤H≤log2(m) for finite support m. Distinguish plug-in empirical estimator, bias correction, and theoretical binomial entropy.
F. Min-entropy H_inf(X)=-log2 max_k p(k), with finite-sample uncertainty; do not interpret aggregate-count entropy as 200 recoverable bits.
G. Conditional entropy H(X_t|X_{t-1}), joint entropy, mutual information I(X_i;X_j), and lagged mutual information, using explicit binning/estimator choices and finite-sample bias controls.
H. Rolling-window statistics: means, variances, entropy, network Z, missingness fraction at 60s, 300s, 1800s; use only complete/qualified windows and report effective sample sizes.
I. Time-series diagnostics: ACF, PACF, Ljung–Box with assumptions, FFT/periodogram, windowing, Welch PSD, wavelets where justified, and multiple-testing-aware peak detection.
J. Cross-device diagnostics: covariance and correlation matrix, lagged cross-correlation, simultaneous-tail counts, permutation/shuffle and block-bootstrap nulls preserving relevant temporal structure.
K. Change-point analysis: CUSUM, offline segmentation / penalized likelihood, sensitivity analysis, false discovery control. Separate candidate discovery from independent confirmation.
L. Null simulations: reproduce the same missingness mask and device count, simulate Binomial(200,0.5) under independence and richer calibrated dependence models; use fixed seeds, disclose all assumptions, retain seed/provenance.
M. Statistical inference: effect sizes, confidence intervals, permutation p-values, family-wise error or FDR correction, preregistration of hypotheses/windows, independent holdout dates and replication.
N. Invariance tests: for any device permutation P, symmetric aggregate F(PX)=F(X), provided identities and missingness travel with values. Define time-translation equivariance for algorithms that support it, not as a property assumed of physical measurements. Test serialization/reordering invariance and numerical tolerance.
O. Optional event comparisons: independently sourced UTC event times, explicit intention and dreaming states (awake, REM, lucid REM, non-REM) only if actual measurements exist. Use blinded window assignment, matched controls, multiple comparison correction, and replication. Historical CSV contains none of these observer labels.
P. Simulation-theory exploratory hypothesis: representation and rotational/equivariance tests are mathematical research ideas, not a validated simulation detector. A toy anisotropy model P(E,theta)=P0(E)(1+epsilon(E)cos(4theta)) is unrelated to this EGG CSV and must not be fit to EGG without a justified observable mapping.
